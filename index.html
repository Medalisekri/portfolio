Built a production REST API for a lost-and-found platform, handling authentication, item lifecycle, real-time chat, and intelligent item matching — deployed on Render with a Neon PostgreSQL database.

  • 🛡️ API Hardening: Added rate limiting (5 posts/day), auto-expiry (60-day listings), owner-only permissions, and full test coverage for all permission and filter logic.

Retrieva — Lost & Found Mobile App

Built the Flutter client for Retrieva — a full-featured lost-and-found app with maps, real-time chat, push notifications, and offline support. Communicates with a custom Django REST API using Firebase ID tokens for auth.

  • 🏗️ Clean Architecture: Enforced a strict 3-layer separation (Screens ➔ Providers ➔ Repositories) so no screen ever touches Dio or API logic directly.

  • 🗺️ Map & Geocoding: Integrated flutter_map with client-side bounds filtering and Nominatim reverse geocoding to render only visible pins without performance hits.
  • 📶 Offline Support: Cached the last item fetch in SharedPreferences so users can browse listings even without an internet connection.
